# 📱 Calculadora con React Native y Expo

Este proyecto es una aplicación móvil de calculadora creada con **React Native** y **Expo**. Está diseñada para realizar operaciones matemáticas básicas en una interfaz limpia y responsiva.

---

## 🚀 Instalación y ejecución

1. Clona el repositorio:
   ```bash
   git clone https://github.com/basurtmart/React-Dev-04-Calculator-App.git
   cd React-Dev-04-Calculator-App

2. Instala las dependencias
   ```bash
   npm install

3. Inicia la aplicación:
   ```bash
   npm start

Puedes abrir la app en:
- [Expo Go](https://expo.dev/go) en tu dispositivo móvil
- Emulador Android o simulador iOS
- Navegado web (modo web)
  
## 🧮 Características
- Interfaz de calculadora con botones táctiles
- Operaciones básicas: suma, resta, multiplicación, división
- Diseño responsivo y adaptable
- Navegación basada en archivos (file-based routing)
